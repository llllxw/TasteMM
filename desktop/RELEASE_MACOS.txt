TasteMM Desktop 0.1.0 - macOS Apple Silicon preview

For Apple Silicon Macs (M series); native arm64 application.
Extract the ZIP and open TasteMM.app. You can move the whole app to Applications.
The CPU runtime and offline model are inside the app. Do not remove its contents.
No Python installation, GPU setup, or internet connection is needed to predict.

Single input: paste a SMILES string and click Predict taste.
Batch input: choose a UTF-8 CSV containing a SMILES column in the Batch CSV tab.
Select a result to view its structure and six probabilities; Export CSV saves
all results, including invalid/empty rows and additional input columns.

This is a research preview with ad-hoc signing, without Apple Developer ID
signing or notarization. macOS may require an explicit first-launch approval.
Consult Apple's instructions for opening an app from an unidentified developer.
The included validation records identify the tested macOS/architecture.
Intel Macs and other macOS versions have not been validated by this build.

The model and resources are unchanged from desktop-v0.1.0-linux: fold 0,
temperature 1.8, six mutually exclusive classes. Salty predictions remain
exploratory (28 salty development records); probabilities are model estimates.

This desktop preview preserves the Linux deployment pipeline. Its truncated
MACCS/Morgan/topological-torsion fingerprint and first-token BERT representation
differ from repository main at 41d333bc0ff6ac332a85e680395c641a7d13c9f7,
which uses MACCS/RDK/ECFP4 and masked mean pooling. Reconcile these against
the authoritative training run before claiming exact manuscript deployment.
The reference checks verify inference regression, not paper accuracy metrics.
