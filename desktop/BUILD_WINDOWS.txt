Rebuild the Windows preview on native Windows x64 with Python 3.10 and Tk.
Keep this source folder and model_bundle together.

python -m venv .venv
.venv\Scripts\python -m pip install torch==2.4.1 --index-url https://download.pytorch.org/whl/cpu
.venv\Scripts\python -m pip install -r environment_build_windows.txt --extra-index-url https://download.pytorch.org/whl/cpu
.venv\Scripts\python build.py
.venv\Scripts\python stage_release.py
.venv\Scripts\python package_release.py --validate

environment_build_windows.txt records every installed build package. Native
Windows output is under dist/TasteMM; distributable archives are in releases.
The source archive excludes model weights and runtime dependencies. Obtain
the original Linux release, verify its SHA256, and extract TasteMM/model_bundle
into this folder as model_bundle. See BUILD_PROVENANCE.json for file hashes.
Alternatively use the separately prepared TasteMM-model-bundle.tar.gz after
checking its checksum. fetch_bundle.py accepts an HTTPS URL and SHA256 via
TASTEMM_MODEL_URL and TASTEMM_MODEL_SHA256 for CI use.

Verify the actual ZIP in a new directory (directory must not already exist):
.venv\Scripts\python validate_relocated.py --archive releases/TasteMM-Windows-amd64.zip --destination ../relocated-check --report releases/validation-relocated-Windows-amd64.json

This makes a repeatable build recipe; it does not promise byte-identical
executables across Windows/Python/build-tool versions.
