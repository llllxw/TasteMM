TasteMM Desktop v0.1.0

Download Linux x86_64, Windows x64 and macOS Apple Silicon packages, matching
source archives and SHA-256 checksums from:
https://github.com/llllxw/TasteMM/releases/tag/desktop-v0.1.0

Extract the complete archive and keep its contents together.
Windows: open TasteMM/TasteMM.exe.
macOS Apple Silicon: open TasteMM.app.
Linux: run ./TasteMM/TasteMM.
The packages include the CPU runtime and offline model resources.

Enter one SMILES string or import a UTF-8 CSV containing a SMILES column.
Select a result to view the molecular structure and six class probabilities.
Export CSV saves predictions, input columns and invalid/empty input status.

Desktop model configuration: fold 0 checkpoint, temperature 1.8, single-label
output ordered as bitter, sweet, umami, salty, sour, tasteless.
The development dataset contains 28 salty records. Probabilities are model
estimates. Validation reports record inference regression on reference inputs.

Desktop features: MACCS/Morgan/topological torsion concatenation truncated to
3,239 bits, with the first BERT token as the sequence representation.
Use the matching release source, feature configuration and bundled checkpoint
to reproduce package predictions. Repository training features are defined
separately in data_process.py.

Windows signing: unsigned. macOS signing: ad-hoc, without notarization.
macOS first-launch instructions:
https://support.apple.com/guide/mac-help/mh40616/mac
The validation records identify tested operating systems and architectures.

Project code: MIT. See LICENSE and LICENSE_SCOPE.txt for resource terms.
Executable checks: --self-test, --self-test-ui, --self-test-workflow.
Pass --report followed by a writable JSON file path to save a report.
