TasteMM macOS build target

The v0.1.0 macOS package targets Apple Silicon (arm64).
Use BUILD_MACOS.txt for native builds, dependency installation, packaging,
signature verification and executable regression checks.

Downloads, source archives and validation records:
https://github.com/llllxw/TasteMM/releases/tag/desktop-v0.1.0

Build artifacts identify the tested macOS version and architecture.
Apple Developer ID signing and notarization are separate distribution steps.
