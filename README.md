# TasteMM

TasteMM provides molecular taste prediction from SMILES.

- [Training, data, evaluation and reproducibility instructions](https://github.com/llllxw/TasteMM/blob/main/README.md)
- [Current training dataset and label mapping](https://github.com/llllxw/TasteMM/tree/main/data)
- [Desktop downloads, platform-specific source, configuration and checksums](https://github.com/llllxw/TasteMM/releases/tag/desktop-v0.1.0)

Use the source version and feature configuration associated with each checkpoint.

Desktop build instructions are in `desktop/BUILDING.txt`, `desktop/BUILD_WINDOWS.txt` and `desktop/BUILD_MACOS.txt`.
